# VouDeMoto 🚀

Plataforma de mobilidade urbana focada em **moto-táxi e entregas**, desenvolvida com base em uma experiência próxima ao padrão Uber.

## 🎯 Objetivo
Criar um aplicativo simples, rápido e confiável para conectar passageiros e motociclistas, com foco inicial em motos e estrutura preparada para expansão futura.

## 🧱 Estrutura do Projeto

- `apps/passageiro` → Aplicativo do passageiro (Flutter)
- `apps/motorista` → Aplicativo do motorista (Flutter)
- `backend` → API, regras de negócio e integrações
- `panel-admin` → Painel administrativo
- `docs` → Documentação técnica e funcional

## ⚙️ Tecnologias (previstas)
- Flutter (Android / iOS)
- Firebase
- Google Maps API
- Pagamentos: Pix e Cartão
